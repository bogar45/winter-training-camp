# Bot Lab

A math game for kids (built for an 11-year-old). The player names a robot, then teaches it real AI skills. Each mission uses real math and installs one robot upgrade.

| # | Mission | Math | Real-world hook |
|---|---------|------|-----------------|
| 1 | Smart Shots | Percents, expected value, multiplying chances | NBA three-point revolution, Moneyball |
| 2 | Power-Up | Doubling, exponents, compound interest | Penny doubling, paper folded to the Moon, AI compute growth |
| 3 | Secret Codes | Clock (modular) math, frequency analysis | Caesar cipher, Alan Turing, browser encryption |
| 4 | Robot Vision | Graphs, y = mx + b, accuracy % | Classifiers; the robot learns the line by itself |
| 5 | Learn from Mistakes | Lines, squared error, gradient descent | How ChatGPT/Claude are trained, Statcast |
| 6 | Robot Talk | Fractions, probability | Build a tiny next-word chatbot |

Also included:
- **Guess the Number**: one estimation puzzle a day, scored by how close you get.
- **Speed Round**: 60-second mental math with combos and a high score. Problem types expand as missions are finished.
- **Lab Report** (for grown-ups): minutes practiced per day, problems solved, accuracy, and settings (sound, unlock all missions, reset).

## Install on iPhone or iPad
1. Open `https://bogar45.github.io/winter-training-camp/botlab/` in **Safari**.
2. Tap **Share → Add to Home Screen**.

Progress is saved on the device. It works offline after the first load.
